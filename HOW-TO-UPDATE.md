# Updating VaultOps Toolkit

1. Download the latest [vaultOps-Setup.exe](https://github.com/infpdev/gtao-heist-toolkit/releases/latest/download/vaultOps-Setup.exe)
2. Run the installer
3. VaultOps will automatically update the existing installation

Done!

> [!NOTE]
> Your settings and hotkeys now automatically persist across updates and reinstalls.
