# Updating VaultOps Toolkit

## Option 1: Automatic Updater (Recommended)

1. Navigate to `C:\Program Files\vaultOps\lib` on your PC
2. Run `vaultOpsUpdater.exe`
3. If the update succeeds, VaultOps will launch automatically

If the updater fails for any reason, follow the steps below to update using the installer.

## Option 2: Reinstall the Latest Version

1. Download the latest [vaultOps-Setup.exe](https://github.com/infpdev/gtao-heist-toolkit/releases/latest/download/vaultOps-Setup.exe)
2. Run the installer
3. The installer will automatically update the existing installation

Done!


> [!NOTE]
> Your settings and hotkeys now automatically persist across updates and reinstalls.
